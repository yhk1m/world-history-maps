# 3D 지형 페이지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `terrain.html` — 구역(직접 그리기·틀·현대 국가·대륙·과거 영토)을 골라 해저 포함 3D 지형 + 역사 지도 덮기를 보고, 파일 하나로 완결된 HTML 로 내보낸다.

**Architecture:** 빌드 없는 ES 모듈. 계산(dem·clip·mesh·overlay)은 three 에 의존하지 않는 순수 함수로 두어 Node 로 테스트하고, `viewer.js` 만 three 를 쓴다. 모듈끼리는 bare specifier(`whm/clip` 등)로 import 하고 import map 이 경로를 정한다 — 페이지에서는 `assets/terrain/*.js`, 내보낸 파일에서는 `data:` URL. 그래서 화면과 내보낸 파일이 같은 코드로 그려진다.

**Tech Stack:** three@0.160.0(+OrbitControls), d3@7.9.0(선택 지도), AWS Terrain Tiles Terrarium, Natural Earth 10m, Node 24 `node --test`.

설계: `docs/superpowers/specs/2026-10-10-terrain-3d-design.md`

### Task 1: clip.js — 다각형 도구

**Files:** Create `assets/terrain/clip.js`, Test `tests/terrain/clip.test.mjs`

함수:
- `unwrapGeom(geom, lon0?) → {geom, lon0}` — Polygon/MultiPolygon 의 모든 경도를 lon0(없으면 첫 고리 평균 경도) ±180 안으로 옮기고 고리 안에서 연속이 되게.
- `bboxOf(geom) → [w,s,e,n]`
- `contains(geom, lon, lat) → bool` — 짝홀 규칙(구멍 포함), MultiPolygon 은 OR.
- `shapePolygon(kind, {lon, lat, rKm, rot}) → Polygon` — kind ∈ rect(정사각, 반변 rKm)·tri(정삼각, 외접원 rKm)·circle(64각). 국소 정거 원통으로 km → 도.
- `sizeKm(bbox) → {w, h}` — 중심 위도 cos 보정.

- [ ] Step 1: 테스트 작성 (`node --test tests/terrain`)

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { unwrapGeom, bboxOf, contains, shapePolygon, sizeKm } from '../../assets/terrain/clip.js';

test('날짜변경선 넘는 고리를 이어 붙인다', () => {
  const g = { type: 'Polygon', coordinates: [[[170, 0], [-170, 0], [-170, 10], [170, 10], [170, 0]]] };
  const { geom } = unwrapGeom(g);
  assert.deepEqual(bboxOf(geom), [170, 0, 190, 10]);
});
test('구멍은 바깥으로 친다', () => {
  const g = { type: 'Polygon', coordinates: [[[0, 0], [10, 0], [10, 10], [0, 10], [0, 0]], [[4, 4], [6, 4], [6, 6], [4, 6], [4, 4]]] };
  assert.equal(contains(g, 2, 2), true);
  assert.equal(contains(g, 5, 5), false);
  assert.equal(contains(g, 11, 5), false);
});
test('원 틀은 중심을 품고 반지름 밖은 품지 않는다', () => {
  const c = shapePolygon('circle', { lon: 10, lat: 45, rKm: 100, rot: 0 });
  assert.equal(contains(c, 10, 45), true);
  assert.equal(contains(c, 10, 45 + 1.0), false); // 1° ≈ 111 km
  assert.equal(c.coordinates[0].length, 65);
});
test('네모 틀 크기', () => {
  const r = shapePolygon('rect', { lon: 0, lat: 0, rKm: 111.32, rot: 0 });
  const [w, s, e, n] = bboxOf(r);
  assert.ok(Math.abs(e - w - 2) < 0.01 && Math.abs(n - s - 2 * 111.32 / 110.57) < 0.01);
});
test('sizeKm', () => {
  const { w, h } = sizeKm([0, 59, 2, 61]);
  assert.ok(Math.abs(w - 111.3) < 1 && Math.abs(h - 221.1) < 1);
});
```

### Task 2: dem.js — 고도 격자

**Files:** Create `assets/terrain/dem.js`, Test `tests/terrain/dem.test.mjs`

함수:
- `decode(r, g, b) = r*256 + g + b/256 - 32768`
- `lonLatToPx(lon, lat, z) → [px, py]` 전 세계 웹 메르카토르 픽셀(타일 256).
- `pickZoom(bbox, maxCells=768, maxZ=12) → z` — bbox 의 메르카토르 픽셀 폭·높이 중 큰 것 ≤ maxCells·2 인 가장 큰 z(격자는 다시 표집하므로 타일 해상도가 격자의 ~2배까지 허용), 최소 0. 타일 수 > 64 면 z 를 내림.
- `gridSize(bbox, maxCells) → {w, h}` — km 비율 유지, 긴 변 = maxCells(구역이 작아 z 해상도가 모자라면 그 해상도까지만).
- `async loadGrid(bbox, {maxCells=768, fetchTile}) → {w, h, bbox, z, data: Float32Array(w*h)}` — 행 0 = 북쪽. fetchTile(z,x,y) → {width, height, data(RGBA)}; x 는 `((x % n) + n) % n` 로 감싸서 요청. 실패 타일은 0 m, `failed` 개수 반환.
- `browserFetchTile(z,x,y)` — fetch → createImageBitmap → OffscreenCanvas getImageData, 2회 재시도.

- [ ] Step 1: 테스트

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { decode, pickZoom, loadGrid, lonLatToPx } from '../../assets/terrain/dem.js';

test('Terrarium 디코딩', () => {
  assert.equal(decode(128, 0, 0), 0);
  assert.equal(decode(127, 0, 0), -256);
  assert.equal(decode(128, 100, 128), 100.5);
});
test('넓을수록 z 가 작다', () => {
  assert.ok(pickZoom([-10, 35, 40, 60]) < pickZoom([6, 45, 8, 47]));
  assert.ok(pickZoom([-180, -80, 180, 80]) <= 2);
});
test('loadGrid 는 주입한 타일에서 표집한다', async () => {
  // 모든 타일: 높이 = 1000 m (r=131,g=232,b=0)
  const tile = { width: 256, height: 256, data: new Uint8ClampedArray(256 * 256 * 4).map((_, i) => [131, 232, 0, 255][i % 4]) };
  const calls = [];
  const g = await loadGrid([179, 0, 181, 2], { maxCells: 64, fetchTile: async (z, x, y) => { calls.push(x); return tile; } });
  assert.equal(g.failed, 0);
  assert.ok(Math.abs(g.data[0] - 1000) < 1e-6);
  const n = 2 ** g.z;
  assert.ok(calls.every((x) => x >= 0 && x < n)); // 날짜변경선 넘어도 감싼 x
  assert.ok(g.w <= 64 && g.h <= 64);
});
test('lonLatToPx', () => {
  assert.deepEqual(lonLatToPx(0, 0, 0), [128, 128]);
});
```

### Task 3: mesh.js — 퍼즐 조각 모형 배열

**Files:** Create `assets/terrain/mesh.js`, Test `tests/terrain/mesh.test.mjs`

- `project(bbox) → {x(lon), z(lat), lon0, lat0, kx, kz}` — km 단위 국소 좌표(x 동쪽, z 남쪽 = three 의 +z).
- `hypso(m) → [r,g,b]`(0~1) 육지 초록→황갈→갈→흰빛, 해저 옅은 파랑→남색.
- `buildArrays(grid, geom, {tint}) → {positions(Float32 xyz, y = 고도 m), colors, top: Uint32 indices, walls: Uint32 indices, base: Uint32 indices, inside: Uint8Array(w*h), baseY}`
  - 칸(i,j)의 네 꼭짓점 중심점이 구역 안이면 그 칸을 포함(셀 중심 판정).
  - 표면: 포함 칸마다 삼각형 2개. 바닥: 같은 칸을 baseY 에서 반대 방향.
  - 옆면: 포함 칸의 네 변 중 이웃 칸이 포함되지 않은 변마다 위 두 점과 바닥 두 점으로 사각형. 옆면 꼭짓점은 따로 복제(색 = hypso*0.55).
  - baseY = min(구역 안 고도) − max(200, 범위의 8%).
  - `tint(lon, lat) → [r,g,b,a] | null` 이면 표면색에 a 만큼 섞음.

- [ ] Step 1: 테스트

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { buildArrays, hypso } from '../../assets/terrain/mesh.js';

const flat = (w, h, v) => ({ w, h, bbox: [0, 0, 1, 1], data: new Float32Array(w * h).fill(v) });
const square = { type: 'Polygon', coordinates: [[[0, 0], [1, 0], [1, 1], [0, 1], [0, 0]]] };

test('전부 포함되면 표면 삼각형 = 2·(w-1)(h-1)', () => {
  const a = buildArrays(flat(5, 4, 100), square, {});
  assert.equal(a.top.length / 3, 2 * 4 * 3);
  assert.equal(a.base.length / 3, 2 * 4 * 3);
  assert.equal(a.walls.length / 3, 2 * 2 * (4 + 3)); // 둘레 변 14개 × 삼각형 2
});
test('구역 밖 칸은 빠진다', () => {
  const half = { type: 'Polygon', coordinates: [[[0, 0], [0.5, 0], [0.5, 1], [0, 1], [0, 0]]] };
  const a = buildArrays(flat(9, 9, 0), half, {});
  assert.ok(a.top.length / 3 < 2 * 8 * 8 * 0.6);
});
test('고도색: 바다는 파랑이 가장 크다', () => {
  const [r, g, b] = hypso(-3000);
  assert.ok(b > r && b > g);
});
```

### Task 4: overlay.js·codec.js

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { prepareOverlay, tintFn, sampler } from '../../assets/terrain/overlay.js';
import { encodeGrid, decodeGrid } from '../../assets/terrain/codec.js';

const fc = { type: 'FeatureCollection', features: [
  { type: 'Feature', properties: { _t: 'area', name: 'A' }, geometry: { type: 'Polygon', coordinates: [[[0, 0], [2, 0], [2, 2], [0, 2], [0, 0]]] } },
  { type: 'Feature', properties: { _t: 'area', name: 'far' }, geometry: { type: 'Polygon', coordinates: [[[50, 50], [51, 50], [51, 51], [50, 50]]] } },
  { type: 'Feature', properties: { _t: 'point', name: 'P' }, geometry: { type: 'Point', coordinates: [1, 1] } },
] };
test('bbox 밖 피처는 뺀다', () => {
  const o = prepareOverlay(fc, [-1, -1, 3, 3], ['#ff0000']);
  assert.deepEqual(o.areas.map((a) => a.name), ['A']);
  assert.equal(o.points.length, 1);
  const t = tintFn(o);
  assert.ok(t(1, 1)); assert.equal(t(2.5, 2.5), null);
});
test('양선형 표집', () => {
  const s = sampler({ w: 2, h: 2, bbox: [0, 0, 1, 1], data: Float32Array.from([0, 10, 20, 30]) });
  assert.equal(s(0.5, 0.5), 15);
});
test('격자 코덱 왕복', () => {
  const a = Float32Array.from([-10994.4, 0, 8848.6, 123]);
  assert.deepEqual([...decodeGrid(encodeGrid(a), 4)], [-10994, 0, 8849, 123]);
});
```

### Task 5: viewer.js — 공용 3D 뷰어

### Task 8: export.js — 파일 하나 내보내기

**Files:** Create `assets/terrain/export.js`

- `buildHTML(payload) → string`:
  - three.module.min.js·OrbitControls.js 텍스트를 jsdelivr 에서 fetch(페이지 세션 캐시).

  - UTF-8 → base64 → `data:text/javascript;base64,...` import map.
  - payload: grid.data 를 encodeGrid, 나머지 JSON. `<script type="application/json" id="payload">`(`</` 이스케이프).
  - 부트 스크립트: decodeGrid → createViewer(document.body, payload).
