# 3D 지형 페이지 설계 (terrain.html)

날짜: 2026-10-10 · 방식 A(브라우저에서 모두 처리하는 정적 페이지)

## 목표
1. 고른 역사 지도의 영역·경로·지점을 3D 지형(해저 포함) 위에 덮어 돌려 본다.
2. 사용자가 고른 구역의 3D 모형을 **파일 하나로 완결된 HTML** 로 내보낸다(인터넷 없이 열림).

## 범위 밖 (YAGNI)
- 위성 사진 표면, 서버·빌드 도구, 로그인, 여러 구역 동시 내보내기, 학교 3D 약도(별도 작업).

## 화면 구성
- 새 페이지 `terrain.html`(+ `assets/terrain/*.js`). 기존 `index.html` 은 레시피 하나와 링크만 추가.
- 왼쪽: 2D 선택 지도(d3 + Natural Earth 육지). 오른쪽: 3D 미리보기(three.js).
- 선택 방식 5가지:
  1. **직접 그리기** — 점을 찍어 다각형, 더블클릭으로 닫기.
  2. **틀** — 네모·세모·원. 끌어서 위치·크기, 손잡이로 회전.
  3. **현대 국가** — Natural Earth 국가 경계(`_도구/ne` 10m 를 줄인 lite 판).
  4. **대륙** — Natural Earth `CONTINENT` 속성으로 국가를 합친 것.
  5. **과거 국가 영토** — 지도 76개의 영역 473개(검색 + 지도별 목록).
- 덮을 역사 지도: 76개 중 하나(없음 가능). 영역·경로·지점 켜고 끄기.
- 「이 지도 전체」 단추: 고른 역사 지도의 범위(bbox)를 그대로 구역으로 — 목표 1 을 이걸로 해결.

## 지형 만들기
- 고도 자료: AWS Terrain Tiles, Terrarium PNG
  `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png`
  (키 불필요, CORS 허용, 해저 수심 포함). 높이 = (R·256 + G + B/256) − 32768 m.
- 확대 단계 z 는 구역 bbox 가 격자 최대 768×768 칸을 넘지 않는 가장 큰 값(대략 대륙 4~5, 지역 8~10). 타일은 최대 64장.
- 타일을 이어 붙인 뒤 구역 bbox 로 잘라 경위도 등간격 격자로 다시 표집.
- **자르기**: 구역 다각형 안쪽 칸만 표면 삼각형을 만들고, 경계를 따라 바닥(고정 깊이)까지 옆면을 세워 퍼즐 조각 모형. 옆면은 고도색을 어둡게 한 단면색.
- 좌표: 구역 중심 기준 정거 원통(x = Δ경도·cos(중심 위도)), 단위 km. 날짜변경선을 넘는 구역은 경도를 중심 경도 기준으로 이어 붙임(unwrap).
- 높이 과장: 1~10배(사용자 요청, 페이지에서는 왼쪽 사이드바 「4 보기」, 내보낸 파일은 화면 위), 기본값은 구역 크기로 자동이되 10배 이하.
- 색: 고도별 색 + 음영(조명 + 정점 법선).
  - 육지 0 → 4000 m 이상: 차분한 초록 → 황갈 → 갈색 → 흰빛.
  - 해저 0 → −8000 m: 옅은 파랑 → 짙은 남색.
  - 해수면: 반투명 평면, 켜고 끄기(기본 켬).
- 역사 지도 덮기:
  - 영역: 지형 표면 정점마다 「어느 영역 안인가」를 미리 계산해 정점 색에 반투명으로 섞음(겹치면 위 레이어 우선).
  - 경로: 지형 높이 + 약간 위로 띄운 선, 끝에 화살촉.
  - 지점: 점 + 이름표(스프라이트).

## 내보낸 HTML (파일 하나)
- 들어가는 것: three.js(min, 문자열로 인라인), OrbitControls, 고도 격자(Int16 → base64), 구역 다각형, 역사 지도 벡터(구역으로 자른 것), 뷰어 코드.
- three.js 는 three@0.160.0 의 `three.module.min.js`·`OrbitControls.js` 를 import map 의 `data:` URL 로 인라인(파일 하나, `file://` 에서도 동작).
- 크기 목표 2~6 MB. 768×768 Int16 ≈ 1.2 MB(base64 1.6 MB) + three.js ≈ 0.7 MB.
- 뷰어 기능: 돌리기·확대, 높이 과장, 해수면, 레이어 켜고 끄기, 범례.
- 출처 표기: 고도 AWS Terrain Tiles(SRTM·GEBCO·ETOPO 등), 경계 Natural Earth, 역사 지도 World History Maps.
- 파일 이름: `3D지형_{구역 이름}.html`.

## 모듈 나누기
- `assets/terrain/dem.js` — bbox·z 고르기, 타일 받기, 격자 만들기(순수 함수 + fetch).
- `assets/terrain/clip.js` — 다각형 안팎 판정, 날짜변경선 unwrap, 틀(네모·세모·원) → 다각형.
- `assets/terrain/mesh.js` — 격자 + 다각형 → three.js 형상(표면·옆면·바닥), 색칠.
- `assets/terrain/overlay.js` — 역사 지도 영역 색·경로 선·지점 이름표.
- `assets/terrain/select.js` — 2D 선택 지도와 다섯 선택 방식.
- `assets/terrain/export.js` — 뷰어 HTML 문자열 조립 + 내려받기.
- `assets/terrain/viewer.js` — 페이지와 내보낸 파일이 **같이 쓰는** 3D 뷰어(내보낼 때는 이 파일 내용을 그대로 인라인 → 화면과 파일이 같은 모습).
- 데이터: `data/lite/ne_countries.json`(국가·대륙용, 간략화) 을 `_도구/export_repo.py` 에서 함께 만듦.

## 오류 처리
- 구역이 너무 넓으면(bbox 경도 폭 > 180°) z 를 낮추고 「넓은 구역이라 지형이 거칠어집니다」 안내.
- 타일 실패: 2회 다시 시도, 그래도 안 되면 그 칸은 0 m 로 채우고 오류 문구.
- 구역이 너무 작으면(한 변 < 2 km) 선택을 거부하고 안내.

## 확인
- 순수 함수(dem·clip)는 Node 로 단위 테스트(높이 디코딩, z 고르기, 다각형 안팎, unwrap, 틀 → 다각형).
- 헤드리스 Chrome(`--disable-gpu`) 화면 캡처 4곳: 알프스(지역), 몽골 제국 영토(과거 국가), 일본 해구(해저), 태평양 전쟁 지도 전체(날짜변경선).
- 내보낸 HTML 을 네트워크 막고(`file://`) 열어 그려지는지 확인.
