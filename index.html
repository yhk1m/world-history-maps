    폴더 구조와 속성

    data/
├─ maps/
│  └─ {권}권_p{쪽}_{지도 제목}/
│     ├─ 영역_전체.geojson
│     ├─ 영역_{나라·왕조·시기}.geojson
│     ├─ 경로.geojson
│     └─ 지점.geojson
├─ countries/
│  └─ {나라}/{나라}_모음.geojson
├─ lite/            웹 시연용 가벼운 판
├─ index.json       지도·나라 색인
└─ 목록.csv

    좌표계 EPSG:4326(경위도) · UTF-8 · 공개본은 약 200 m 간격으로 단순화했습니다.

    속성뜻
    name이름(한글) · name_en 영문
    period시기 — 범례가 가리키는 시점
    kind영역 종류: 국가 · 세력권 · 문명 · 식민지 · 종교 · 기타
    category경로: 정복·원정로 · 이동로 · 교역로 · 항해로 · 진격로 · 경계선
    지점: 수도 · 도시 · 격전지 · 항구 · 유적
    year지점에 붙은 연도(예: 앙카라 전투 1402)
    legend교과서 범례 문구 그대로
    source교과서 권·쪽

      // 프레임마다 세력(key)별 영역 + 그 프레임의 진격로

  for (const key in f.areas)
    morph(layer[key], frames[i - 1]?.areas[key], f.areas[key]);
  drawRoutes(f.routes);   // 3D 모형과 같은 화살표(띠 + 넓은 머리)가 앞으로 자라며 그려짐
});

      B크로키 — 지도 위에 그리며 생각하기

      바탕 지도를 깔고 펜·형광펜·화살표·글자로 그려 봅니다. 그린 선은 경위도로 저장되어 확대해도 땅에 붙어 있고, 그림은 PNG 로, 선과 글자는 GeoJSON 으로 내보낼 수 있습니다.

      바탕 레이어

      크로키는 파일 하나로도 있습니다 — 따로 열기 · HTML 파일 받기. 받은 파일을 그대로 열어도 동작하고, 코드를 고쳐 나만의 도구로 바꿔 써도 됩니다.

      C모핑 — 같은 나라의 여러 판

      같은 나라의 여러 판(시기별 영역)을 이어 붙이면 제국의 팽창과 축소를 애니메이션으로 보여 줄 수 있습니다. 나라별 모음에서 판이 둘 이상인 나라를 고르세요.

      // d3 + flubber
const proj = d3.geoEqualEarth().fitSize([w, h], fc);
const path = d3.geoPath(proj);
const a = path(stageA), b = path(stageB);
const tween = flubber.interpolate(a, b, { maxSegmentLength: 3 });
d3.select('path').transition().duration(1600)
  .attrTween('d', () => tween);

      E면적 재기 — 제국은 얼마나 넓었을까

      구면 면적을 계산해 판끼리 비교합니다. 아래 표는 고른 나라의 판별 면적을 이 페이지에서 바로 계산한 값입니다.

      # Python · geopandas
import geopandas as gpd
g = gpd.read_file('data/countries/오스만 제국/오스만 제국_모음.geojson')
g['km2'] = g.to_crs('+proj=cea').area / 1e6
print(g[['name', 'period', 'km2']].sort_values('km2'))

      G수업에서

      • 겹쳐 보기 로마·한·당의 최대 영역을 한 지도에 — 같은 시기, 다른 세계.
      • 길 따라가기 알렉산드로스 원정로의 총 길이를 재고 하루 행군 거리를 추정.
      • 오늘의 나라와 비교 영역과 현대 국경을 겹쳐 지금 어느 나라들에 걸쳐 있는지 찾기.
      • 버퍼 분석 교역로에서 100 km 안 도시들 — 길이 도시를 만든다.
      • 타임랩스 지도 쪽 순서대로 영역을 넘기며 역사의 흐름을 한 장면으로.
      • 단면도 히말라야·안데스·알프스를 가로질러 단면을 긋고 산지의 높이와 모양을 비교.
      • 빙하기 해수면 해수면을 −120 m 로 내려 황해·베링 해협이 육지로 드러나는 모습 보기.
      • 해구와 해령 일본 해구·대서양 중앙 해령을 3D 와 단면도로 — 판의 경계를 지형으로 읽기.

      Method

      그림에서 데이터로

      1. 지리참조지도마다 도시 기호·해안 특징점 12~50개를 기준점으로 잡았습니다.
      2. 추출PDF 속 벡터 도형에서 영역과 경로를 그대로 뽑고, 빗금·그림은 색으로 나눴습니다.
      3. 웹지도 기준 보정교과서 투영과 웹 메르카토르의 차이를, 최적 투영 + 박판 스플라인으로 폈습니다. 교과서 해안선과 실제 해안선의 대응점을 지도마다 수백 개씩 자동으로 더했습니다.
      4. 해안·국경 맞춤영역의 해안 쪽 테두리는 Natural Earth 해안선에, 현대 국경과 나란히 가는 구간은 국경선에 붙였습니다.

      알아 둘 점

      옛 경계는 교과서 그림의 단순화만큼(수십 km) 실제와 다를 수 있습니다. 바다가 대부분인 영역(교역망, 태평양 세력 범위)은 해안 맞춤을 하지 않았습니다. 지도별 판단 사항은 저장소의 목록과 속성에 남겨 두었습니다.
